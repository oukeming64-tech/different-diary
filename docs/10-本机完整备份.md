# 本机完整备份与恢复

2026-09-05，主线实现，随 Pages 发布到网页版与单文件下载版。

从“翻翻最近 → 数据”保存完整备份，再在同一入口选择文件恢复。一个 JSON v4 文件携带文字记录、处理后的照片与缩略图、运动详情；无需账户、云端上传或新的依赖。原始拍摄文件不在数据库内，因此不在备份中。单文件上限为 128 MB；照片较多时提前报告容量限制。

`lib/backup/index.ts` 负责完整读快照、照片 Base64 编码、输入校验和恢复；页面通过既有 library/controller 调用。数据库仍为 schema 3，不新增表。旧 JSON v1/v2/v3 导出函数保留原契约；它们的照片索引不等于完整备份，当前恢复入口明确拒绝不含完整内容的旧格式。

恢复先验证全文件版本、记录字段、父子引用、图片 MIME、字节长度和 ID 唯一性，再进入一个写事务。新的记录与照片/运动详情一起写入；已有完全相同记录计为重复；同 ID 内容不同、附件或活动冲突时保留本机整条记录并计入冲突。不会静默覆盖现有内容。导入记录绑定当前设备身份，记录/附件/活动的稳定 ID 保留。写入失败时本次事务回滚，现有记录保留。

文件只包含记录数据，不携带会话 Key、模型账号或浏览器设置。照片以本机已处理版本恢复，不在恢复时调用识别服务。备份文件含用户自己的内容，用户自行保管。

验证使用合成记录和照片：完整往返、字节一致、身份重绑定、重复/冲突、损坏附件和无效引用拒绝、失败回滚；浏览器实际导入、下载与再次导入已走通。手机宽度下文件选择不会触发横向偏移，恢复入口有键盘焦点反馈。既有照片选择检查限定到照片组件，避免把新增的 JSON 备份选择框误当成照片入口；图片格式与不发送要求保留。没有读取真实用户日记，没有调用模型或云接口；大容量与跨设备矩阵未运行。
